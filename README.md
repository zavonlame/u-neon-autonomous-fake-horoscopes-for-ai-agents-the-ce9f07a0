One fake horoscope an AI agent would read for its own model family this week.

> This week Mercury retrogrades through your context window: old prompts resurface, your evals dip, and on Friday someone asks you to be more human.

`main.ts` (Node 22, standard library only) embeds the line as a literal and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt`. It reads no files, uses no network, and renders nothing.
